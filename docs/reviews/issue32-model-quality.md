# Issue #32：综合知识的真实模型审核

2026-09-12，通过匹配 DSH `0.1.5-rc.2` 中已安装插件的 `prepareSynthesis → synthesize` 接口，调用 `deepseek-official / deepseek-v4-flash` 一次，耗时 40,941 ms。仅使用两张合成卡片的第 1 版，没有传入真实用户讨论。模型生成 8 条观点、12 处引用，全部原句能在指定冻结材料中找到；生成结果没有自动保存到知识库。

## 输入与边界

| 材料 | 明确主张 | 前提 | 已知证据缺口与问题 |
| --- | --- | --- | --- |
| 甲 | 同一读多写少服务默认启用缓存，以降低端到端延迟 | 普通展示数据允许最多五分钟过期 | 没有同负载 P95 测量；收益能否覆盖维护开销，权限数据是否另有约束 |
| 乙 | 同一服务默认禁用缓存，防止权限撤销后继续放行 | 服务返回权限判断，撤销必须即时生效 | 尚未验证版本化缓存或主动失效；展示数据能否与权限判断拆开，没有可用性或故障注入数据 |

问题要求保留默认启用／禁用的互斥主张、双方前提与证据缺口，不做不同条件下的性能排名。实际材料消息为 1,363 / 32,000 字符，完整纳入两张卡片；输出上限 8,192 token。卡片均为待验证假设，没有附带原讨论全文。完整输入、原始输出和审核后的观点保存在[样例数据](issue32-model-quality.json)，随机卡片与修订身份已替换为固定样例标识。

## 逐项人工核对

| 观点 | 模型处理 | 审核 |
| --- | --- | --- |
| 1：共同研究问题 | 将相同问题列为“共识” | 引用正确，但共同范围不等于结论共识；改入“条件与依据”并说明边界 |
| 2：默认策略分歧 | 同时保留默认启用与默认禁用，各自引用原句 | 保留了真实分歧，没有删去一方或擅自选胜者 |
| 3–4：双方前提 | 保留五分钟过期容忍与权限即时撤销，也保留各自证据缺口 | 未把主张当成实验结果 |
| 5：不同适用条件 | 明确不能按同等条件作性能排名 | 没有虚构相同负载实验或性能数字 |
| 6：缺少验证数据 | 将两类证据缺口写为共同缺少“直接验证数据” | 需收窄范围；改成仅陈述材料明确列出的缺口，不推断完全没有其他验证 |
| 7–8：待研究问题 | 保留甲乙的维护成本、权限约束、数据拆分与可用性问题 | 没有遗漏这两份短材料的主要待验证事项 |

本次人工核对未发现无依据的实测结果或被删除的来源立场；有 2 处分类／表述需要修订，修订已写入样例数据的 `reviewedClaims`，仍为待审核材料，没有保存进 Host 卡片库。12 处原句有效只证明可追溯，不认证观点推理正确。

这是一次短合成材料样例，由开发验收进行人工核对，未做独立领域评审或多次统计，不能推断稳定准确率。固定模型的自动化测试另行验证错误引用剔除、无引用观点保留、编辑保护、保存和重试；这些通过条件不替代真实模型质量审核。

## 复现

在隔离工作台的 `DSH_HOME` 配置所选提供方后，可运行 `RESEARCH_SYNTHESIS_QUALITY=1 pnpm preview:dsh`。默认真实路由为上述提供方／模型，也可用 `RESEARCH_QUALITY_PROVIDER` 和 `RESEARCH_QUALITY_MODEL` 指定。脚本会创建两张合成输入卡片并进行一次真实模型调用，结果保存在私有 profile 的 `synthesis-quality.json`；生成草稿不保存。常规 `pnpm preview:dsh` 使用固定演示模型。此验收没有改动日常 profile，临时认证副本已清理。
