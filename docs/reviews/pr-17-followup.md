## 实际 Chrome 验收

1. 创建一张全中文、Method／Draft、没有来源的卡片。通过已安装插件的 Gateway 对尚未创建目标的预览执行读取及重复预览，两者与最初记录一致，明确返回未创建。
2. 选择该卡和另一个工作区，冻结 794 字符的预览。在原生创建返回后，将独立日志目录替换为不可写路径，并暂时阻止目标状态读取。问题、工作区和材料保持锁定；没有原生用户请求，模型调用没有增加。
3. 仅恢复目标读取，保持日志不可写。核对后得到同一预留目标，记录仍是 `prepared`、`targetCreated: true`，打开入口可用，输入仍锁定，预览逐字不变。
4. 恢复日志存储后重试同一次提交，Host 确认接收。目标和请求 ID 均不变，只有一条带该 `rpcId` 的原生用户消息，其文字与 794 字符预览完全一致。模型回答状态与接收状态分别展示。
5. 选中主题唯一卡片，将视口缩放至 120%，移出卡片并关闭编辑层。选择变为 `null`，平移和缩放保持不变，空图显示提示。使用真实鼠标点击关闭按钮中心，提示消失；按钮计算样式为 `pointer-events: auto`。重新搜索并加入卡片后没有恢复旧选择。
6. Host 全部知识范围内搜索 `draft` 和 `method` 均无结果；搜索“缓存”能找回该卡片。Host 回归另外覆盖全部五个文字字段、历史版本排除及主题筛选。
7. 重启同一隔离 Host，在实际页面重新打开目标 Graph 的材料记录。沿用记录和卡片完全相同；目标仍只有一条对应请求，三个来源各 36 条事件逐条相同。重启后的这些只读操作调用模型 0 次。

来源准备含标题共 12 次固定模型调用，本轮新讨论及标题再增加 2 次；其余上述操作不调用模型。全程未使用真实模型凭据，浏览器 `pageerror` 为 0。旧真实模型质量样例仍见[独立审核](issues-6-10-model-quality.md)，不把本轮固定响应验收当作模型质量证明。
