# 会话标题生成与摘要速读

日期：2026-09-12。需求：[Issue #33](https://github.com/benz-ai-x/dsh-research-graph/issues/33)。基线：main `83c08b3`。用户要求根据对话生成可辨识的会话标题，并把摘要改为短篇要点、突出关键信息、使用 Markdown 排版。

## 本轮实现

- [x] 会话详情身份区新增“生成标题”，工作区／目录图和可用的主题来源均可操作。
- [x] 先展示可编辑建议，“应用标题”通过 DSH 原生重命名保存。所选会话与输入会话不同时，操作仍指向所选会话；侧栏和图节点使用原生列表更新。
- [x] 取消或切换选择时终止生成并忽略迟到结果。保存失败保留编辑；其他位置已改名时提示重新生成；列表更新可确认回包丢失的保存结果。
- [x] 摘要为一句概览、最多五项关键结论和三项待办。目标长度为中文 200–350 字／英文 100–160 词，校验上限为 1,000 个 Unicode 字符，概览 140 字符、每项 160 字符，均含 Markdown 标记。
- [x] 复用 DSH 公共 Markdown 渲染：无序列表、加粗关键词及浅色背景强调、行内代码、斜体与来源链接。概览使用轻量强调块，正文可选择复制。
- [x] 完整摘要过长时仅压缩重试一次；不直接截断句子或 Markdown。保留 4,096 输出 token 预算供模型推理；失败时保留原有有效摘要。
- [x] 双语 README、领域说明和 ADR 同步。

## RC.2.3 后的摘要高亮增强（2026-09-12）

用户在实际摘要截图中指出高亮不够明显。本次从 main `976e48b` 调整摘要区域的 Markdown `strong` 样式：原先为 12% 浅蓝底色与 650 字重，改为暖黄色荧光笔底色、700 字重和 2px 的强调下缘，增加少量内边距；仍保持行内流动与 `box-decoration-break: clone`，允许重点自然换行。

颜色全部来自匹配 DSH 的语义令牌：`state-warn-secondary` 与 `state-warn-tertiary` 按 40%／60% 混合，文字使用 `label-primary`，随宿主主题自动调整。按官方 RC.2 的实际令牌计算，浅色主题文字与底色的对比约 13.90:1，深色主题约 6.00:1。高亮范围仍仅为摘要中的 Markdown 加粗片段，已有缓存摘要中的重点无需重新生成即可获得新样式。
