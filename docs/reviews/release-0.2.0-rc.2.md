# DSH Research Graph 0.2.0-rc.2 release acceptance

This is the first adaptation of the DSH 0.2.0-rc.2 line; per the release policy the plugin takes the full target version. The 0.1.7-rc.2 → 0.2.0-rc.2 upstream delta spans 448 commits and 1638 files, but the adaptation is version-pin-only: every surface the plugin imports (27 `@deepseek-ai/*` packages), injects (9 client services), or pins (peer + direct dependencies, plus `types/` standalone adapters, test fixtures, and `cordis.patch.yml`) was diffed package-by-package between the tags, and **no breaking change reaches any of them — every dependency-surface change is additive**. The `dsh-llm` message model, Typert protocol/registry, Session format catalogs, `sessionProjectionCache`, storage packages, `useSessionStatus`/`SessionSummary`/`ctx.uiWorkspace.openSession`, the locale/`configForms` inject chain, and the profile-boot plugin peer enforcement are all version-bump-only. The additive changes (`ISessions.fork`/`UiWorkspace.forkSession` optional `onCreated`, `SessionInput`/`ComposerKeyboard.submit` optional `source`, new `MessageSubmission*` contract types, `TypertGateway.hasLiveClient()`, new `productAnalytics`/`userQuestions` remote namespaces) are not called by the plugin in breaking positions. The one neighboring presentation change is Host-side: workspace rows without a durable title now show a localized “Untitled” instead of the project-basename fallback; `SessionSummary.displayTitle` itself is unchanged and the graph still recovers durable titles for never-opened Branches through non-activating projection reads. No source, test, or fixture change was required, and none is included.

## Acceptance boundary

Existing manual arrangements remain until **Relayout** (Undo-safe, collapse- and reading-state-preserving); **Fit** adjusts the viewport; Topic arrangements synchronize only through explicit **Save arrangement**. The cold-start observation — an unopened Branch temporarily lacking its durable title and inherited-source summary in native lists — remains unlocated at the Host layer and is not claimed as repaired; since 0.1.7-rc.2 the graph itself recovers retained titles and facts through non-activating projection reads, so the phenomenon is not visible to graph users, and the new Host-side Untitled fallback affects only the native directory presentation. Arbitrary dense graphs can still have crossings or obstructed terminals. The two structured research-direction requirements in [Issue #32](https://github.com/benz-ai-x/dsh-research-graph/issues/32) remain deferred.
