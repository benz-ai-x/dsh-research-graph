## 修复结果

| 审查发现 | 修复与验证 |
| --- | --- |
| 保存成功但回执丢失，改稿重试被拒绝 | 第一版综合原子地保存准备身份。同一准备、同一卡片的新修订可以恢复保存；Host 重启后仍成立，原修订与冻结材料不变。重复提交同一修订幂等，不允许借此覆盖来源卡片或采用其他准备。旧版无此可选字段的修订仍能读取和按修订地址编辑。 |
| 冻结原文被当前正文替换 | 默认直接展示冻结快照；“核对当前原文”单独加载当前正文。正式界面测试覆盖边界不变但文字已变，以及原文不可用，两种情况下冻结内容均保留。 |
| 分支已创建，命名／主题失败时无法打开 | 原生创建确认后记录 `created`，界面同时提供打开和恢复入口。只有持久种子、尚未确认原生创建时仍为 `prepared`；重试采用同一子会话身份。 |
| 返回原轮次后异步刷新丢失焦点 | 主题列表刷新保留图谱，画布身份只随主题切换，不随成员变化重建。完整注册界面回归刻意将成员更新延迟到返回之后，验证原按钮仍连接在 DOM 中并保持焦点。 |
| 两条修订编辑路径重复初始化 | `KnowledgeEditor` 内共用 `loadRevisionDraft`，统一正文、可编辑来源、综合材料和草稿基线；直接编辑及从阅读进入编辑的现有回归通过。 |
