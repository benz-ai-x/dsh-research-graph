## PR #42 复审 P2 追加修复

复审固定在首轮提交 `63a5987`，Standards 无发现，Spec 发现一个 P2：真实 DSH 已采用子会话、但工作区关联失败时，创建命令会抛出 `session/workspace-attach-failed`，因此仅在命令正常返回后标记 `created` 会隐藏已存在目标的打开入口。本次使用官方 `remoteErrorOf` 读取错误码与结构化身份，同时匹配目标会话和请求工作区后，保存 `created` 与错误信息；重试继续完成同一目标的工作区关联、命名及主题关联。

新增四项回归：原生创建控制器在工作区写入失败后保留目标，Host 重启后恢复关联并保留子会话新增的第三轮；两项身份不匹配的反例；以及工作区失败后的界面打开与重试入口。核心回归先在旧实现复现 `prepared`／`created` 差异，再验证通过；原审查探针复跑也通过。原生控制器测试只替换 Agent 组合与工作区存储，继续讨论通过原生 Session 恢复和持久化 API 写入，不代表在实际 Chrome 中注入过该故障。
