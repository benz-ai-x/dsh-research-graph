# DSH 0.2.3-alpha.1 compatibility analysis

This adaptation moves Research Graph from DSH `0.2.2-rc.5` to `0.2.3-alpha.1`. The plugin version, exact `@deepseek-ai/dsh-llm` peer, and every direct `@deepseek-ai/dsh-*` dependency become `0.2.3-alpha.1`. Research records, Workspace Folders, historical Branch recovery, Merge provenance, native Session backup/restore, and offline Merge recovery retain their existing ownership boundaries.

## Scope and method

- Old upstream: `dsh-v0.2.2-rc.5`, commit `9c2670d3bce5275e0d1610272958121af87787bb`.
- New upstream: `dsh-v0.2.3-alpha.1`, commit `d98f5d68519215da48f3002da2cb9c9d2068d81d`.
- The full range contains 2,343 commits and 7,260 changed files. The compatibility surface is therefore derived from the plugin manifest and `dsh.client.inject`, actual source/type/test imports, build externals and inline-only modules, profile fixtures, and the vendored sources rather than unrelated upstream product changes.
- Each consumed surface records changed, unchanged, or accepted behavior below. The four compiler faces and runtime suites resolve the final uncertainties.
- No `docs/upgrade-guide/v0.2.3-alpha.1` directory exists at the target tag; the source and declaration diffs are the compatibility evidence.

## Coverage inventory

The reviewed surface includes LLM messages/errors, Agent and default-model selection, Session V4 and validation, Session Controller/Query/SQLite/Projection/Reference, JSONL persistence and format catalogs, native log export, Workspace and Workspace Controller, Typert protocol/registry/Gateway/Remote Access, Cordis and Schemastery, Storage and Storage Domain, attachment references and local-store fixtures, Subagent addresses/catalogs, Session stats/title/turn outline/token/goal/todo projections, Client store/connection/locale/shortcuts/product analytics, Conversation/layout/renderer/slots/primitives/session/session-status, vendored sidebar/workspace/default-workspace, and the standalone/test/profile build faces.

## Dependency and release-age handling

All direct DSH dependencies and the exact LLM peer move from rc.5 to alpha.1. The new status package is an explicit dev dependency and Client injection; no broad Controller dependency is added merely to reuse its directory helper.

The latest direct target artifact observed during adaptation was `@deepseek-ai/dsh-client-ui-slots@0.2.3-alpha.1`, published `2026-11-22T03:43:03.476Z`. Local pnpm commands and CI/Publish temporarily use `pnpm_config_minimum_release_age=0`; the workflow override must be removed after **2026-11-23T03:43Z**. The install added no new `minimumReleaseAgeExclude` entries.
