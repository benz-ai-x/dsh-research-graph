# Read Session facts through non-activating projections

DSH 0.1.7 exposes a non-activating projection read: `refreshProjections(sessionId)` lands a full projection baseline into the Session list store without activating the Session's Agent or opening its conversation. The graph uses it to restore durable titles and to show workload facts, replacing guesswork with Host-retained evidence.

On scope resolution the view refreshes every non-subagent canvas member in small batches. The Host single-flights each Session per connection and short-circuits ready reads, so scope-churn re-runs cost nothing. Failed reads stay silent: the node keeps its previous presentation, and a later scope change retries naturally. The plugin never merges projection blocks itself; the Host's projection store owns the cached/sequenced/seeded semantics, and the graph consumes only the final per-row values.

Facts are presentation only. Cards stay on their fixed geometry: a closed-turn count joins the existing meta line, and the newest turn's bounded prompt preview rides the card's hover text. The inspector gains a stats block with the model route, turn and step counts, wall times, cumulative tokens, goal, todo progress, and the newest turn's prompt/response previews. Without projections every fact stays absent and the node behaves exactly as before.

Two restraint calls follow from the upstream contracts. Context pressure is shown as plain text, never as a color threshold: the upstream fields sample different moments and are explicitly not a metering input. Turn previews stay on hover and in the inspector rather than on the card face, because a graph view shows many Sessions side by side and is more public than a conversation view. The Agent preset is folded onto the node model but not rendered on the card: the projection reports the effective preset including the Host-wide default, so a badge would repeat one identical value across every card.

The same refresh routes around the known cold-start presentation gap: the list path admits a stored projection block only when its cached identity matches the Session header exactly, so an unopened Branch can temporarily present a directory-derived title and omit its inherited-source facts until natively opened. The non-activating read takes the cold full-log path instead, restoring the durable title and facts for the graph. The underlying Host-side identity mismatch remains unlocated; the plugin's recovery makes it invisible to graph users without claiming a Host fix.
