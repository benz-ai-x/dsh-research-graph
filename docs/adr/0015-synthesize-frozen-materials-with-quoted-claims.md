# Synthesize frozen Research Materials with quoted claims

Issue #32 adds Synthesis after graph exploration: compare two or three selected materials, review disagreements and conditions, and manually retain a new Knowledge Card. This extends ADR 0009's single-turn material limit to a continuous completed-turn range. The existing one-to-three material Reuse admission and recovery protocol remains unchanged. Synthesis accepts two-to-three cards, ranges, or mixed selections and refuses overlapping ranges and repeated cards. Host capture always verifies exact completed boundaries; it does not infer boundaries from matching text or accept client-supplied source bodies.

Shared Host capture freezes the addressed card revision/body/source labels or the full selected original discussion range. A stable preparation identity retains the selection, research question, exact model text and 32,000-character budget in Host storage. Synthesis rejects the whole over-budget selection, without the whole-turn truncation used by Extraction. Each selected card must belong to the chosen topic at preparation. Later source changes or unavailability do not replace a retained preparation.

The auxiliary model returns a title, question, kind and editable claims in four categories: agreements, disagreements, conditions/evidence and open questions. The prompt retains opposing views with their premises and requests verbatim quotes using zero-based material indexes. Each quotation must occur in the indicated frozen card body or included original messages; card source labels cannot stand in for original text. Invalid generated citations are removed and counted, while unsupported claims remain visible for verification. Manual save refuses invalid quotations until corrected or removed. This validates traceability, not inference quality or truth.

Generation is explicit and cancellable and creates no Session or saved Card Revision. Re-generation appends a new draft, retaining prior edits and materials. Closing or removing unsaved edits uses the existing DraftGuard; save errors retain the same draft and retry identity. New Synthesis saves must create an independent card in the preparation's topic. The first saved revision also retains its preparation identity atomically with the card. A changed retry from that same preparation may append a revision to the same target after a lost receipt, including after Host restart; unrelated preparations and pre-existing source cards remain rejected. Older revisions without this optional identity remain readable and editable through their saved revision address. Editing a saved Synthesis references its own immutable prior revision and retains the same frozen inputs. Narrative fields derive from the reviewed claims so search, normal Reuse, and export reflect manual changes consistently. Draft is the default status; confirmation is a user edit.

Only cited cards produce a directed Synthesis Relation (`source card → Synthesis card`) labeled with the quoted source revision. Cited original ranges use existing Source Relations. All frozen inputs remain available in the reader and export, including uncited inputs clearly distinguished from claimed provenance. Source-card links open the exact revision; the frozen-range panel renders the retained snapshot directly, with a separate explicit Original reader that distinguishes original text from retained excerpts. Source updates do not rewrite old revisions or edges. Source cards detached from the topic are read as dependencies so their direct provenance remains visible without reattaching them.

Browser wire parsers reuse the repository's dependency-free primitives. Zod is confined to Host storage adapters. Card storage remains additive within the existing domain with immutable old revisions; previews use an additional table. Host/Gateway tests cover conflicts, exact quotations, invalid/unsupported claims, mixed continuous ranges, budgets, source updates/unavailability, restart, explicit and idempotent saves, search/export/Reuse. Interaction tests cover prompt protection, retained drafts, regeneration, closing, retry and cited-revision reading. Packed acceptance retains real DSH services and replaces only model transport with an explicitly fixed fixture; it is evidence of protocol and workflow correctness, not real-model comparative reasoning quality.
